TI MSPM0 Gamepad Controller

Rice ELEC 220 · Spring 2026

A hardware-first build: an embedded gamepad controller on a TI MSPM0, written in C/C++ in Code Composer Studio. Sampled an analog joystick through the ADC and converted readings into directional commands, wired in push-button input, and drove LED output for real-time feedback. Moved from continuous polling to timer-driven sampling, then to interrupt-driven ISRs for responsive, real-time input handling — one of the strongest parts of the build. Peripherals were configured and read directly through memory-mapped registers and pointers, not a higher-level abstraction layer.

Timer-driven → interrupt-driven (ISR) · direct register access via pointers
