How I approach the work

Most "stock prediction" projects are quietly broken — they leak future data, "predict" yesterday's price, and report accuracy with no costs or benchmark. I build to avoid every one of those traps. The rigor is the contribution.

🔬

Correctness over hype

Look-ahead-free backtests, realistic transaction costs, and honest benchmarks against buy-and-hold. I report null results when the edge isn't real — because that's the truth.

⚙️

Production discipline

Reproducible environments, single-source-of-truth config, and regression tests that specifically catch data leakage. Research code held to software standards.

⚡

Systems that ship

C++ performance cores wrapped in Python product layers, real-time streaming pipelines, and live deployed dashboards — not notebooks that only run on my laptop.

News-Sentiment Trading Signal

Stocks.io · Python · DuckDB · scikit-learn · Streamlit
● LIVE DEMO

A financial-news sentiment signal for US equities, evaluated with a correct backtest — no look-ahead bias, 5bps transaction costs, benchmarked against buy-and-hold. The headline result is an honest one: the signal is contemporaneously real but has ~zero next-day predictive edge, exactly what market efficiency predicts. A walk-forward volatility model then shows price history subsumes the news.

EdgePulse — Real-Time Forecasting & Anomaly Detection

C++ · Python (ctypes) · Streamlit · FastAPI
● LIVE DEMO

A stream-agnostic monitoring pipeline that ingests a live signal, forecasts its next value, and flags anomalies in real time. The forecasting core is written in C++ and called from Python via ctypes (with a pure-Python fallback), anomalies use a robust median/MAD z-score that resists outliers, and the hosted demo plugs into a live cryptocurrency feed — updating every second with no page reloads.

MarketLab — Vectorized Backtesting Engine

Python · pandas · NumPy
◆ OPEN SOURCE

A lightweight equity backtesting engine built on fully vectorized pandas/NumPy pipelines — designed to run roughly an order of magnitude faster than naive Python loops. Plug in a strategy (moving-average crossover, momentum) and get P&L, max drawdown, and Sharpe, plus equity and drawdown charts. A clean API keeps adding new strategies simple.
