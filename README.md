# shekinahokunbo.github.io

Personal portfolio site for **Shekinah Okunbo** — ECE + Data Science, Rice University.

Live at **https://shekinahokunbo.github.io**

A single, self-contained static page (`index.html`) with photos and a
downloadable resume under `assets/`. No build step, no dependencies. Hosted
on GitHub Pages, served straight from the default branch.

## Structure
```
index.html
assets/
  images/            headshot, gallery photos, project thumbnails
  resume/            downloadable resume PDF
```

## Local preview
```bash
python3 -m http.server 8600
# open http://localhost:8600
```
